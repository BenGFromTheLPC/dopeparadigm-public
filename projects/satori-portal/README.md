# Satori Portal

## What It Is

**Satori Portal** is the larger admin/web/mac direction planned around the Satori system.

## Role in the Ecosystem

If Satori becomes the personal command center, Satori Portal is the larger operator-facing expansion layer: the place where broader management, review, and control workflows can live over time.

## Audience

- internal use
- admin/operator workflows
- future system expansion

## Platform Direction

- web
- macOS
- admin/operator surfaces

## Why It Matters

The Dope Paradigm ecosystem is not only about public apps. It is also about building tools that make it possible to manage publishing, content, systems, and future automation in a way that feels intentional and coherent.

## Status

Future-facing but important enough to represent publicly at a high level.
