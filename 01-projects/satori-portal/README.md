# Satori Portal

## What It Is

**Satori Portal** is the larger macOS direction planned around the Satori system and the broader content-management world behind it.

## Role in the Ecosystem

If Satori becomes the mobile access layer, Satori Portal is the larger desktop expansion layer: the place where broader management, review, planning, and control workflows can live over time, with **Tabularium** underneath as the long-term state and memory layer.

## Audience

- internal use
- admin/operator workflows
- future system expansion

## Platform

- macOS
- Web (Coming soon)

## Why It Matters

The Dope Paradigm ecosystem is not only about public apps. It is also about building tools that make it possible to manage publishing, content, systems, and future automation in a way that feels intentional and coherent, instead of scattered across disconnected tools.

## Status

Future-facing but important enough to represent publicly at a high level.
