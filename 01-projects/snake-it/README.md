# Snake-It!

## What It Is

**Snake-It!** is a public-facing iPhone game built as a modern take on a classic arcade idea. It is designed around quick runs, clean swipe controls, growing difficulty, and the kind of replay loop that makes it easy to pick up for a minute and keep going longer than planned.

## Role in the Ecosystem

Snake-It! shows that the Dope Paradigm world is not limited to music apps, admin systems, or internal tooling. It expands the ecosystem into playful consumer software and proves that the same artist-first creative direction can translate into a small, focused game product.

## Audience

- casual mobile players
- App Store users looking for quick replayable games
- people discovering the broader range of the Dope Paradigm ecosystem

## Platform

- iPhone

## Current Direction

Current work has been centered around:
- fast swipe-based gameplay
- score-chasing and replayability
- bonus pickups that change pacing
- polished start, game-over, and settings flows
- safe-area-aware UI for modern iPhone screens
- lightweight monetization that stays out of active gameplay
