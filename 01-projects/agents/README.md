# Agents

## What It Is

**Agents** is the execution layer of the Dope Paradigm ecosystem. This project page documents the high-level role of each machine-based agent and how they support creative operations without exposing private orchestration details.

## Role in the Ecosystem

The agents are designed to turn strategy into action. While Satori provides control and Tabularium provides state and memory, the agents provide distributed execution across different hardware profiles and responsibilities.

## Agent Breakdown

### Jarvis (Mac Mini)

- orchestrator and strategic coordinator
- routes work across the system
- tracks outcomes and keeps operations aligned

### Rick (Raspberry Pi)

- monitoring and awareness node
- focused on infrastructure visibility and health checks
- supports reliability and system-state awareness

### Dell (Precision Tower)

- compute-heavy and media-processing worker
- handles workflows that need stronger processing capacity
- supports execution tasks that benefit from dedicated compute

### Que (OptiPlex 7090)

- content generation and distribution support node
- intended for social-facing workflow execution
- expands output capacity for recurring content operations

### DPSS (Dope Paradigm Senses Server)

- physical interface layer for real-world interaction
- handles sensory I/O surfaces such as mic input and screen output
- designed to bridge software orchestration with real-world control loops

## Current Direction

The agent layer is currently focused on:
- stable host-level access and identity management
- clean role separation across machines
- public-safe execution transparency
- alignment with Satori control flows and Tabularium state
- future command-bus coordination
