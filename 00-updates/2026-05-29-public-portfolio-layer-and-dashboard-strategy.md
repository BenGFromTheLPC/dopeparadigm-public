# 2026-05-29 — Public Portfolio Layer and Dashboard Strategy

Not all important work is user-facing. Some of it is about making the ecosystem legible and sustainable.

## What Changed

- dashboard metrics in the internal portal were split into cleaner long-term categories
- operator control over realtime vs manual dashboard refresh behavior was added
- public portfolio strategy for the Dope Paradigm ecosystem was formalized
- a public-safe GitHub layer was defined so private progress can still become visible progress

## Why It Matters

As the system grows, clarity matters just as much as features. Internal metrics need to tell the truth about the current catalog, user behavior, and lifetime activity. Publicly, the work also needs a place where momentum can be seen without exposing private implementation.

## Public-Safe Summary

This was a strategy week as much as a product week: tightening internal metrics while also designing how the outside world will see the work.
