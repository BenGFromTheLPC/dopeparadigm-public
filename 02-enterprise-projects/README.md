# Enterprise Projects

This section is for anonymized write-ups about enterprise and workforce-facing apps, internal tools, and operational systems built in professional environments outside the Dope Paradigm ecosystem.

## Purpose

These pages exist to show:

- app structure
- workflow design
- mobile and desktop operational thinking
- data-capture strategy
- internal-tool product thinking
- public-safe system design experience

## Important Boundary

This section should **not** expose:

- employer names
- company-sensitive data
- internal datasets
- private operations details
- security-sensitive implementation details
- code views

## What Should Be Shared

These pages should focus on:

- what kind of problem the app solved
- who the users were at a high level
- platform choices
- workflow improvements
- app structure and feature organization
- how the system supported real operations
