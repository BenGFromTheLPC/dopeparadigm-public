# Templates

This folder exists mainly to help **Codex / AI-assisted updates** stay consistent when adding or revising public content in this repo.

## What This Folder Is For

These templates are the first stop before drafting:

- public update posts
- project pages
- enterprise project pages
- future release-style summaries

They are here to keep the repo consistent in tone, structure, and level of detail.

## How They Should Be Used

Before a new public post or project draft is written, the agent should:

1. check the relevant template in this folder
2. follow the structure closely for the first draft
3. keep the write-up public-safe
4. avoid code views or secret-sauce implementation details
5. wait for approval before pushing meaningful new public-facing content

## Important Boundary

These templates are **authoring scaffolds**, not the full publishing policy.

The source of truth for publishing rules, approval flow, and public/private boundaries is the **Public Github Portfolio Manifesto** in Notion.

Use this folder for consistency.
Use the manifesto for policy.
